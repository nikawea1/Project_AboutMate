# Tierra Mate

Многостраничный сайт концептуального бренда аргентинского чая мате Tierra Mate. Выполнен на HTML5, CSS3 и JavaScript.

## Страницы сайта

- `index.html` — главная страница: презентация бренда, девиз, ключевые показатели и интро-блоки.
- `about.html` — о компании: история марки, интерактивный таймлайн развития с 2018 по 2024 год и этапы производства.
- `catalog.html` — каталог из 20 позиций мате с фильтрацией по вкусам, модальными окнами товаров и формой заказа с корзиной.
- `gallery.html` — фотогалерея процесса производства с полноэкранным просмотром (лайтбокс с поддержкой стрелок клавиатуры и клавиши Esc).
- `country.html` — интерактивная климатическая карта Аргентины с описанием регионов произрастания йерба мате.
- `contacts.html` — контакты, карта, форма обратной связи с валидацией, блок отзывов с оценками и аккордеон частых вопросов (FAQ).

## Основные возможности

- Светлая и тёмная тема интерфейса (выбор сохраняется в `localStorage`).
- Адаптивная вёрстка под мобильные телефоны, планшеты и мониторы с использованием мобильного бургер-меню.
- Плавная анимация появления контента при скролле через `IntersectionObserver`.
- Интерактивные модули на JS: климатическая карта, фильтры каталога, модальные окна, аккордеон FAQ, лайтбокс галереи.

## Структура проекта

```text
index.html         главная страница
about.html         о компании и таймлайн
catalog.html       каталог продукции и заказ
gallery.html       фотогалерея с лайтбоксом
country.html       климатическая карта Аргентины
contacts.html      контакты, отзывы и FAQ
css/style.css      стили сайта и темы оформления
js/main.js         интерактивная логика
img/               фотографии товаров, галереи и иконки
```

## Как открыть

Открыть файл `index.html` в любом браузере.
